# TrayCollector (托盘图标收集器)

一个轻量级的 Windows 任务栏托盘图标托管与恢复工具。

https://github.com/user-attachments/assets/350d4d1d-7735-479f-bbda-cdcffa5b95a2

## 功能
TrayCollector 通过 API Hook 技术，接管并收集目标程序的托盘图标。当系统任务栏发生重建或电源模式切换时，本工具会自动将图标重新绘制到任务栏上，确保你不会丢失对后台程序的控制权。

> **杀软误报说明**
> 由于本软件的核心原理依赖于向目标程序注入 DLL 以实现接管，部分杀毒软件可能会将其拦截或报毒。这是正常现象，本工具完全开源且无任何恶意行为，请放心使用或加入白名单。

## 编译说明
* **环境依赖**：Visual Studio (推荐 2026) 
* **依赖库**：包含 MinHook (请通过 NuGet 还原包)
* **编译架构**：支持 x86 与 x64 目标程序

## 使用方法
1. 运行 `Controller.exe`。
2. 右键点击收集器的托盘主图标，选择“添加要收集的程序...”。
3. 选择你想要接管的目标程序（如 `test.exe`）。
4. 目标程序会被自动注入，并由收集器接管其托盘图标及鼠标点击事件。
